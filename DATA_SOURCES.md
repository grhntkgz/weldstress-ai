# Source measurements and derived numerical artifacts

Christian Dänekas, *Research Data on Fatigue Tests of As-Welded, Deep-Rolled, and HFMI-Treated Joints*, LUIS version 1.0 (2025), DOI [10.25835/0dojws6u](https://doi.org/10.25835/0dojws6u), CC BY 4.0, is the original experimental source. The raw third-party dataset archive is linked rather than mirrored. Retained processed/registered surfaces are derivatives; preserve this attribution and the source terms when using them.

The cohort is C02, C05, C16, E21, G04, G07, G08, G16, G25, H12, H19, X10 and X23, all V1-S355-AW. Five documentary parent-plate groups C/E/G/H/X determine LOPO splits; independently certified production batches/scan-session independence are not established. Previously aligned/processed scans do not independently resolve raw registration or physical weld-toe accuracy.

The expanded private release supplies project-derived processed geometry, idealized planar-rear FE solids/meshes, M1/M2 native numerical results, T2 reference arrays, trained neural/XGBoost weights, predictions, features and evaluation/provenance records. FE stresses and learned fields are computational derivatives, not experimental stress labels from the source dataset. Synthetic rear/closure surfaces are not scanned surfaces. Material/loading constants are assumptions.

The original two small preparation ZIPs have disclosed path normalization in SOURCE_PROVENANCE.csv. Expanded release ZIP members preserve original bytes and historical paths via release/ARTIFACT_MANIFEST.csv; no metric, label, coordinate or stress array was changed to package them. The release is private and the upload does not select a new open code/data license or create a DOI.
