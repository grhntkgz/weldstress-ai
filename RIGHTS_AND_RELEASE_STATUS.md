# Rights and release status

Visibility: PRIVATE preparation. DOI creation: not requested. Scientific research: CLOSED.

No software license is selected by this preparation step. Code, derived data, third-party dependencies and the source experimental dataset have separate rights. The dataset's CC BY 4.0 attribution does not automatically choose a license for project code or all derived material. The owner should confirm applicable rights and select code/data licenses before public distribution.

Public-release checklist:

- Confirm source attribution, authors/contributors and distribution rights.
- Choose explicit code and derived-data licenses.
- Decide and document whether the necessary bulk arrays, checkpoints and FE/CAD files will be supplied, linked or withheld.
- Validate intended reproduction commands with the curated inputs; do not imply an unavailable standalone workflow.
- Review exported provenance for local identifiers; path normalization is disclosed and original hashes remain retained.
- Create and verify an immutable scientific version/tag and record its full commit identifier.
- Make the repository public only when authorized, verify external access, then update the manuscript's availability statements.

No new DOI is required by this repository setup. Any journal-specific archival requirement must be checked separately before submission.
