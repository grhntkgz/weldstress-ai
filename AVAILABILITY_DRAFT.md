# Data and code availability

**Data availability.** The original scans and experimental metadata are publicly available from Dänekas [12], version 1.0, at https://doi.org/10.25835/0dojws6u under CC BY 4.0. The processed geometries, numerical FE reference stresses, trained model checkpoints, prediction fields and evaluation records supporting this study are publicly available in the companion repository, https://github.com/grhntkgz/weldstress-ai, through the versioned release reproducibility-2026-10-24 (https://github.com/grhntkgz/weldstress-ai/releases/tag/reproducibility-2026-10-24). File manifests and SHA-256 checksums identify the archived artifacts. The derived stress fields are numerical FE quantities, not experimentally measured stresses.

**Code availability.** The research code for geometry preprocessing, feature construction, model training and inference, evaluation, and figure generation is publicly available at https://github.com/grhntkgz/weldstress-ai. The archived computational version is identified by release reproducibility-2026-10-24, pinned to commit 8ff92d44a5a4a8d7e17d93af19821b13c33da4e2. Download, verification and restoration instructions are provided in the repository. The recorded neural environment uses CPU PyTorch 2.6.0; the separate XGBoost environment uses XGBoost 3.0.2, scikit-learn 1.6.1 and NumPy 2.2.6. Historical path dependencies and licensed ANSYS software remain relevant to FE regeneration. A clean end-to-end reproduction in a new environment has not been tested.

Repository visibility was changed to public on 24 October 2026 with explicit owner authorization. Public accessibility does not add a new software or derived-data license, DOI, physical validation or clean-environment reproduction.
